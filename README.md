# Mitchell Site

A starter GitHub Pages site for sharing research and Streamlit apps.

## GitHub Pages

The landing page (`index.html`) is served automatically by GitHub Pages from the `main` branch root. Enable Pages in **Settings → Pages → Source: Deploy from a branch (main, / root)**.

## Streamlit App

A starter Streamlit app lives in `app.py`.

### Running locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Structure

```
.
├── index.html        # GitHub Pages landing page
```
